Zepp OS 1.0 Mi Band 7 Gemini 2.5 / 2.0 / 1.5 Open Source

🚀 Method 1: 1-Click Cloud Build (GitHub Actions)

The easiest and most trusted way. Build your personal installation package with your API key directly on GitHub's infrastructure with zero local setup.

  1. Fork this repository to your GitHub account (click the Fork button at the top right of GitHub).
  2. In your fork, navigate to the Actions tab.
  3. Select the workflow Build Personal Band Package from the left sidebar.
  4. Click Run workflow, paste your Google AI Studio API key, and click the green button.
  5. Wait ~45 seconds. Open the completed run and scan the generated QR code directly off your screen using the Zepp app!

🔒 Method 2: In-Browser Patcher (100% Client-Side)

Configure and download a patched gemini_band.zpk directly in your web browser. Everything runs locally in browser memory — no data is sent to any server.

🛡️ Client-Side Guarantee: Your API key is processed exclusively inside your browser using JSZip. It never leaves your device and is not saved or transmitted anywhere.

💻 Method 3: Compile from Source (Offline Zeus CLI)

For developers who prefer compiling from source on their local machine:

# 1. Clone the repository
git clone https://github.com/poluprovodnik228/mi-band7-gemini.git
cd mi-band7-gemini

# 2. Install Zeus CLI
npm install -g @zeppos/zeus-cli

# 3. Create config.js with your API key
echo "module.exports = { GEMINI_API_KEY: 'AIzaSyYourKeyHere' };" > config.js

# 4. Build .zab and .zpk
zeus build

📲 Zepp App & Developer Mode Setup

  1. Pair via Zepp MB7 mod: Unpair Band 7 from Zepp Life / Mi Fitness. Install the Zepp MB7 mod and pair the band (it will pair masked as Amazfit Band 7, unlocking full network & developer APIs).
  2. Enable Developer Mode: In Zepp, go to Profile ➔ Settings ➔ About and tap the version number 7 times.
  3. Install: Return to Profile ➔ Amazfit Band 7 ➔ Developer Mode, tap the QR scanner icon in the top right, and scan the QR code.
⚠️ Troubleshooting "Download failed (error null)":
The Zepp internal downloader rejects unencrypted local HTTP addresses (http://192.168.x.x). Downloads must use a secure public HTTPS URL (such as GitHub Actions / GitHub Pages zpkd1://...).
